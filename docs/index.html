双译 · Shuangyi

浏览器双语对照翻译扩展。翻译模型由你自己选，没有后端，文本只发往你配置的那个接口。

安装

目前通过 GitHub Release 的 zip 手动安装，商店版本准备好之后这里会补上链接。

  1. 到 Releases 下载最新版本的 shuangyi-translate-<版本>.zip，解压到一个不会被清理的固定目录。
  2. 打开 chrome://extensions，右上角开启「开发者模式」。
  3. 点「加载已解压的扩展程序」，选择解压出来的文件夹。
  4. 点扩展图标旁的齿轮进设置，在「翻译服务」里配置模型。默认的 Google 免费翻译不需要配置就能用。

开发者模式下浏览器每次启动会显示一个提示气泡，不影响使用。关闭开发者模式后未打包扩展不会加载。

功能

  • 整页双语对照或仅译文，译文样式可选下划线、虚线、高亮、引用线或不做修饰
  • 悬停翻译单段（按住 Shift）、划词气泡翻译、输入框连按三次空格翻译
  • 视频双语字幕，支持标准 WebVTT 字幕轨与 YouTube 自绘字幕
  • PDF 阅读页：提取文本层、重建成段落、双语对照阅读，可导出 Markdown
  • 多套翻译服务档案随时切换：OpenAI 兼容接口、Anthropic、Gemini、Ollama、DeepL、Google 免费翻译，以及任意自定义 HTTP 接口
  • 每套档案独立的系统提示词、术语库与专家身份；专业内容的术语能保持一致
  • 站点级「总是翻译 / 从不翻译」规则，母语页面自动跳过
  • 每段译文都能复制、就地编辑、带上前后文重新翻译

隐私

扩展没有自己的服务器，不收集、不上传任何数据，代码里没有统计或埋点。翻译时浏览器把页面里的文本直接发送到你自己配置的接口。
