# 提审时要填的说明文字

Chrome Web Store 在提交时会要求填写「单一用途」和每个权限的用途理由。这里是可以直接粘贴的文案。

## 单一用途说明（Single purpose）

```
在网页上提供双语对照翻译，并允许用户自行选择翻译所使用的模型服务。
```

## 权限用途理由

### `storage`

```
用于在本地保存用户的扩展设置（目标语言、显示样式、交互偏好、站点规则）及其自行填写的翻译服务配置（接口地址、API Key、模型名、提示词、术语库）。这些数据仅保存在用户本机浏览器中，不会上传到任何服务器。
```

### `contextMenus`

```
用于提供右键菜单项，包括「翻译/还原此页面」「翻译选中文本」「总是翻译此网站」「从不翻译此网站」和「扩展设置」。这些是翻译功能的常规入口，不涉及数据收集。
```

### 访问所有网站（`<all_urls>` 主机权限）

```
本扩展的核心功能是在用户浏览的任意网页上注入双语对照译文。要做到这一点，必须能够读取当前页面的文本节点以识别可翻译段落，并把译文插回原位置。用户浏览的网站不可预知，因此无法限定域名列表。

本扩展仅在用户主动触发翻译（点击悬浮球、按快捷键、悬停、划词）或为其单独设置了「总是翻译」的站点上读取页面内容。译文只会发送到用户自己配置的翻译服务，扩展本身没有服务器。不读取与翻译无关的内容，不记录浏览历史。
```

## 数据使用声明（Data usage）填写指引

提审表单里的数据使用部分，请按下列方式如实勾选：

| 项目 | 选择 | 说明 |
|---|---|---|
| 网站内容（Website content） | **勾选** | 待翻译的页面文本会被发送到用户自己配置的第三方翻译接口 |
| 个人身份信息 | 不勾选 | 不收集 |
| 健康信息 | 不勾选 | 不收集 |
| 金融与支付信息 | 不勾选 | 不收集 |
| 身份验证信息 | 不勾选 | 不收集 |
| 个人通信 | 不勾选 | 不收集 |
| 位置 | 不勾选 | 不收集 |
| 浏览历史 | 不勾选 | 不记录 |

三个合规承诺（表单里的复选框）都可以如实勾选：

- 不会将用户数据出售给第三方 ✅
- 不会将用户数据用于与扩展单一用途无关的目的 ✅
- 不会将用户数据用于判定信用度或放贷 ✅

## 常见驳回原因自查

| 风险点 | 本项目情况 |
|---|---|
| 远程代码（Remote code） | 不加载任何远程脚本，全部逻辑随包分发；请求体模板是纯数据，由本地代码解释执行 |
| 权限冗余 | 已移除未使用的 `scripting`、`activeTab` 权限 |
| 资源暴露 | 未使用 `web_accessible_resources`，不向网页暴露扩展内部资源 |
| 隐私政策缺失 | 见 `privacy-policy.md`，需托管为公开网址 |
| 描述提及竞品 | 提交文案中不得出现其他扩展名称 |
| 数据使用声明不实 | 必须勾选「网站内容」 |
