# 栖译 隐私政策

最后更新：2026 年 3 月

栖译（以下简称「本扩展」）是一款浏览器翻译扩展。本政策说明本扩展处理哪些数据、发送到哪里、以及你如何控制它。

## 一句话总结

本扩展没有自己的服务器。它只在你的浏览器本地保存设置，翻译时把待翻译的文本直接发送到**你自己配置的翻译服务接口**。

## 本扩展收集的数据

**本扩展不收集、不上传任何数据到开发者或任何第三方服务器。**

本扩展不存在开发者运营的后端服务、不存在统计上报、不存在崩溃收集、不存在广告或用户画像。

## 本扩展在本地保存的数据

以下数据保存在你的浏览器本地存储（`chrome.storage.local`）中，不会离开你的设备，除非你主动导出：

- 你的设置：目标语言、显示样式、交互偏好、站点规则（总是/从不翻译的域名）
- 你填写的翻译服务配置：接口地址、API Key、模型名、系统提示词、术语库
- 译文缓存的运行期数据（仅存于内存，浏览器或扩展重启后清空）

你可以随时在扩展设置页清除缓存或恢复默认设置，也可以在卸载扩展时一并删除全部数据。

## 数据发送到哪里

当你触发翻译时，本扩展会把**当前页面中待翻译的文本片段**发送到你自行配置的翻译服务。具体接收方取决于你的配置：

- 若你使用 Google 翻译：文本发送到 `translate.googleapis.com`
- 若你使用 DeepL：文本发送到 DeepL 的 API
- 若你配置 OpenAI 兼容接口、Anthropic、Gemini 或其他服务：文本发送到**你所填写的那个接口地址**
- 若你使用 Ollama 或本地服务：文本只在你自己的机器或局域网内传输

这些服务的隐私做法由其各自的隐私政策约束，与本扩展无关。**请只配置你信任的翻译服务。**

除上述翻译请求外，本扩展不会将数据发送到任何其他地方。

## 本扩展申请的权限及用途

| 权限 | 用途 |
|---|---|
| `storage` | 在本地保存你的设置与服务配置 |
| `contextMenus` | 提供「翻译此页面」「总是/从不翻译此网站」等右键菜单项 |
| 访问所有网站（`<all_urls>`） | 在网页上注入译文、识别段落。这是核心功能所必需：翻译工具需要能读取你正在浏览的页面 |

本扩展不读取与翻译无关的页面内容，不记录你的浏览历史。母语页面会自动跳过，除非你为该站点单独设置了规则。

## 关于 API Key

你填写的 API Key 保存在浏览器本地，仅用于向你配置的那个接口发起请求。本扩展不会将 Key 发送到其他任何地方。

## 儿童隐私

本扩展不面向儿童，也不收集任何个人信息。
