# 双译 — 双语对照网页翻译

> 提交到 Chrome Web Store 时，把下面的内容分别填入对应字段。

## 名称（Name）

```
双译 — 双语对照网页翻译
```

## 简短说明（Summary，132 字符以内）

```
双语对照网页翻译：整页、悬停、划词、输入框翻译。模型自己选——OpenAI 兼容、Claude、Gemini、Ollama，或任意自定义接口。
```

## 详细说明（Description）

```
让网页变成双语对照，模型由你自己选。

■ 自己选模型，不被绑定
双译不绑定任何一家翻译服务。你可以保存多套配置随时切换，不用重填参数：
· OpenAI 兼容接口 —— DeepSeek、Moonshot、OpenRouter、LM Studio、vLLM…
· Anthropic Claude
· Google Gemini
· Ollama 本地模型
· 任意自定义 HTTP 接口（自己填请求地址、请求头、请求体、结果取值路径）
还可以用 Google 免费翻译开箱即用，或接 DeepL。

■ 双语对照，原文不丢
译文以可调样式注入在原文之后：虚线下划线、实线下划线、高亮背景、左侧引用线。一键还原原文。

■ PDF 翻译
把论文、报告这类 PDF 拖进扩展，提取文本层并重建成段落，双语对照阅读，可导出 Markdown 归档。（不支持扫描件 OCR，也不做原版式还原）

■ 译文可以改
每段译文都支持单段复制、就地编辑和重新翻译。重译会自动带上前后段落作为上下文，并绕过缓存，所以结果真的会不一样，也更准确。

■ 导出双语对照
看完的文章可以一键导出成 Markdown（原文 + 译文成对、保留标题层级），直接存进笔记工具长期归档。

■ 上下文感知的翻译质量
同一批段落一起交给模型，并要求它保持全文术语、人称与语气一致 —— 这是大模型相对传统翻译引擎的优势所在。再配合每套模型自己的术语库与专家身份，专业内容的术语能保持统一。

■ 视频双语字幕
视频本身带字幕时，自动在画面底部叠加双语字幕（原文 + 译文），支持标准 WebVTT 字幕轨，以及 YouTube 的自绘字幕。

■ 四种翻译方式
· 整页翻译 —— Alt+A
· 鼠标悬停翻译单段 —— 按住 Shift 悬停
· 划词翻译 —— 选中文字弹出译文气泡
· 输入框翻译 —— 连按 3 次空格，把正在写的内容译成目标语言

■ 为专业内容准备
每套模型配置都可以有自己的术语库（原文=译文）和 AI 专家身份（医学、法律、计算机…），术语更统一，行文更专业。译文字号和样式都能调。

■ 按站点设置
某些站点总是翻译、某些从不翻译，右键即可设置。母语页面自动跳过。

■ 你的数据只经过你自己选的接口
设置和译文缓存只保存在浏览器本地。翻译时网页文本直接发送到你自己配置的接口，双译没有中转服务器，不收集、不上传任何数据。

■ 源码开放，可以自己查
源代码以 AGPL-3.0 开源：github.com/istoo/shuangyi-translate 。任何人都能核对它如何处理数据，也可以自行编译安装。扩展本身没有后端，也不包含任何统计或埋点代码。

■ 快捷键
Alt+A 翻译/还原页面 · Alt+W 切换双语对照/仅译文
```
